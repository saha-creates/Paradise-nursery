# Paradise Nursery Shopping Application

## Project Name

**Paradise Nursery — Online Plant Shop**

## Project Overview

Paradise Nursery is a dynamic e-commerce web application designed for an online plant nursery. The application allows users to browse a collection of plants, view plant information, add plants to a shopping cart, and manage their selected items.

The project was developed as a final project to apply web development concepts and create a functional, interactive, and user-friendly shopping experience.

## Features

* Browse a collection of plants
* Display plant images, names, descriptions, and prices
* Add plants to the shopping cart
* Increase the quantity of cart items
* Decrease the quantity of cart items
* Remove plants from the cart
* Dynamically update cart item quantities
* Automatically calculate the total cost of items
* Navigation bar for easy movement between pages
* User-friendly and interactive interface

## Application Pages

### Landing Page

Introduces users to Paradise Nursery and provides navigation to the plant collection.

### Product Page

Displays the available plants along with their images, names, descriptions, prices, and options to add them to the shopping cart.

### Shopping Cart

Displays the plants selected by the user and allows them to adjust quantities or remove items. The cart dynamically updates the total number of items and the total cost.

The goal of the Paradise Nursery Shopping Application is to demonstrate the practical application of web development skills by creating a functional online shopping experience where users can browse plants, select products, manage their cart, and view the calculated purchase total.

## Conclusion

Paradise Nursery provides a simple and interactive online plant-shopping experience. The project combines frontend development, dynamic data handling, user interaction, and shopping-cart functionality to create a complete e-commerce application.
